## 5) Replace Turing/Hopper with Level 1-4 Tasks

All lesson tasks must now use this structure:

- `Level 1` = beginning to learn (supported, scaffolded, minimal code changes)
- `Level 2` = making progress (guided changes with some independence)
- `Level 3` = making good progress (independent feature build with hints)
- `Level 4` = meeting target (full challenge/extension, justify design choices)

Task design rules for every lesson:
- Include all 4 levels explicitly.
- Levels must build on the same lesson objective.
- Level 1 and 2 should include worked steps.
- Level 3 and 4 should reduce scaffolding and increase decision making.
- Provide a quick self-assessment check at the end of each level task.
