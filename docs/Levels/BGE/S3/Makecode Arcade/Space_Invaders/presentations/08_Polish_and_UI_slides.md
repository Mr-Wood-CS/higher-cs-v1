# Slide 1: Space Invaders Lesson 8 - Polish and UI

- Learning Intention: Improve player feedback and overall presentation.
- E&Os: `TCH 3-15a`, `TCH 3-13a`, `TCH 3-14b`
- Benchmarks focus: refining a solution through testing and UX improvements.

# Slide 2: Success Criteria

- I can add score and life UI.
- I can add title/start messaging.
- I can add suitable sounds/effects.
- I can justify one polish choice with player impact.

# Slide 3: Starter / Retrieval

- Which feedback helps a player most: score, lives, sound, or effects?
- What makes a game feel "finished"?

# Slide 4: Teacher Demo - Core UI

- Add `info.setScore(0)` and `info.setLife(3)` in `on start`.
- Add `game.splash("Space Invaders")`.
- Check readability and timing.

# Slide 5: Teacher Demo - Audio and Scene

- Add laser and hit sounds.
- Add optional background image in `scene`.
- Keep visuals uncluttered for gameplay clarity.

# Slide 6: Build Checkpoint

- UI values update correctly.
- Sound cues match actions.
- Start flow is clear and not too slow.

# Slide 7: Level 1-4 Task Choices

- Level 1: Add score, life, and splash title.
- Level 2: Add at least two event-based sounds.
- Level 3: Add coherent visual theme (background + sprite consistency).
- Level 4: Run a peer UX test and implement one evidence-based improvement.

# Slide 8: Plenary / Exit Question

- Which polish change most improved player understanding, and how do you know?

# Slide 9: Homework / Extension

- Capture a screenshot and annotate 3 UI choices with purpose.
