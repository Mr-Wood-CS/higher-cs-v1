# Slide 1: Space Invaders Lesson 9 - Level Up

- Learning Intention: Scale difficulty and create progression.
- E&Os: `TCH 3-15a`, `TCH 3-13b`, `TCH 3-14a`, `TCH 3-14b`
- Benchmarks focus: modelling progression rules and refining full systems.

# Slide 2: Success Criteria

- I can increase challenge over time.
- I can trigger level changes based on score/time.
- I can keep game balance fair and testable.

# Slide 3: Starter / Retrieval

- What is the best trigger for level-ups: score, timer, or defeated enemies?
- How can we increase challenge without making the game unfair?

# Slide 4: Teacher Demo - Level Variable

- Create `level` variable and set to `1`.
- Add level-up check (for example, every 10 points).
- Display level change message.

# Slide 5: Teacher Demo - Difficulty Scaling

- Increase spawn rate or enemy speed each level.
- Optionally add stronger enemy types on higher levels.
- Keep increments small and test after each change.

# Slide 6: Build Checkpoint

- Reach level 2 in test play.
- Confirm challenge increases but remains playable.
- Confirm game still tracks score/lives correctly.

# Slide 7: Level 1-4 Task Choices

- Level 1: Add level variable and one simple level-up trigger.
- Level 2: Increase one difficulty factor each level.
- Level 3: Increase two factors (e.g., speed + spawn rate) with testing notes.
- Level 4: Build a complete progression model for 3+ levels and defend your balancing choices.

# Slide 8: Plenary / Exit Question

- Which scaling rule gave the best balance between challenge and fairness?

# Slide 9: Homework / Extension

- Write a mini design spec for "Level 10" including enemies, speed, and bonus behaviour.
